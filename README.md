# Giacomo Digital Studio
Prototype static website.

Open through a local web server (JSON translations use fetch), e.g. VS Code Live Server, Textastic preview, or `python3 -m http.server`.

## Structure
- index.html
- css/style.css
- js/app.js
- i18n/it.json
- i18n/en.json
- i18n/es.json
- images/ (replace placeholders with final assets)
